# Romeva Website — v0.1

A static, responsive Romeva landing page built from the approved project brief and the assets supplied in the conversation.

## Included
- English / Arabic language switcher
- Services-first landing page
- Real Romeva portfolio videos
- Home Start portfolio visual
- WhatsApp, email, phone and social links
- Responsive mobile layout
- Premium ivory / beige visual direction
- Basic reveal animations

## Important
The supplied Romeva logo and portfolio assets are copied into `assets/` without editing their visual content.

Analytics is intentionally not activated yet because no measurement account/ID was supplied. The site can be connected to an analytics platform before publishing.

## Deploy
This is a static site. It can be deployed for free on services such as GitHub Pages, Netlify, or Cloudflare Pages. A custom domain can be connected later without rebuilding the site.
